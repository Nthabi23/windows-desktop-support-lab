# Windows Desktop Support & Troubleshooting Lab

## Project Overview

This project demonstrates practical IT Support skills through Windows 11 system diagnostics, network troubleshooting, DNS resolution testing, and performance investigation.

The lab uses a Windows 11 Pro computer to practise common troubleshooting procedures, document findings, and develop structured technical support reports.

## Objectives

- Collect basic computer system information.
- Test network connectivity using command-line tools.
- Diagnose DNS resolution issues.
- Investigate Windows performance and resource usage.
- Document troubleshooting procedures and results.
- Develop professional IT Support documentation.

## Lab Environment

| Component | Details |
|---|---|
| Operating System | Windows 11 Pro |
| Processor | Intel Core i5-10210U |
| Memory | 8 GB RAM |
| Storage | HDD |
| Tools | Command Prompt, Task Manager, Windows system utilities |

## Completed Exercises

### 1. Network Connectivity Test

**Command:** `ping 8.8.8.8`

Results:
- Packets sent: 4
- Packets received: 4
- Packet loss: 0%
- Average response time: 8 ms

**Conclusion:** The computer successfully communicated with the test destination during the diagnostic.

### 2. DNS Resolution Test

**Command:** `nslookup google.com`

Results:
- DNS lookup completed successfully.
- IPv4 and IPv6 addresses were returned.
- The DNS server responded to the query.

**Conclusion:** DNS resolution for google.com was working during the test.
